# ITMO AITH: DL+NLP HW2

Независимое решение второй домашней работы по классификации новостей Lenta.ru по
топикам с использованием эмбеддингов.

Для ДЗ 2 в git хранятся только код и отчётные файлы. Сырые данные, предобученные
эмбеддинги и артефакты экспериментов не коммитятся.

## Что реализовано

- стратифицированный сплит `60/20/20` по `topic`;
- обучение собственных `Word2Vec`-эмбеддингов на train;
- intrinsic-проверка через `most_similar` и `doesnt_match`;
- сравнение `LogisticRegression` с тремя вариантами эмбеддингов:
  - собственный `Word2Vec`;
  - предобученный `Navec`;
  - предобученный `RusVectores`;
- улучшение лучшего варианта через `tf-idf`-взвешенное усреднение эмбеддингов;
- финальное сравнение моделей на test;
- автоматическая фильтрация слишком редких тем перед сплитом, если на выбранной
  подвыборке они не позволяют сделать корректный стратифицированный `60/20/20`.

## Отчётный прогон

Для итогового отчёта использован локально подготовленный стратифицированный
`20k`-сэмпл из более крупного processed-набора. Это позволило честно сравнить
три пространства эмбеддингов и `tf-idf`-взвешенный вариант в разумное время.

Команда отчётного прогона:

```bash
python3 src/hw2_pipeline.py \
  --preprocessed-sample-path data/hw2_sample_20k_processed.csv \
  --sample-size 20000 \
  --embedding-sources custom_w2v,navec,rusvectores \
  --w2v-epochs 6 \
  --artifacts-dir artifacts_hw2/run_default \
  --seed 42
```
